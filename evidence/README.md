# Local Verification Evidence

These files are generated by the public command-line tools on the Windows laptop. All workload data and model responses are fixtures. No GPU inference, RDMA, Kubernetes provisioning or GPU KV transfer was measured.

- `queue-fixture.json`: real local queue/worker execution with synthetic token demand, completed tasks and drained workers.
- `moe-fixture.json`: analysis of the public synthetic expert-routing trace, including a static placement proposal.
- `collective-fixture.json`: analysis of invented rank timings to verify arithmetic; bandwidth values are not real network measurements.
- `chaos-fixture.json`: three isolated CPU fixture faults, detected failover and fixture state recovery.
- `network-recovery-fixture.json`: actual localhost SSE interruption and event-ID resume over a durable SQLite fixture ledger.
- `range-stream-fixture.json`: actual interrupted localhost weight response, resumed offset and SHA verification.
- `weight-fixture.json`: bounded CPU-memory loading of one tiny synthetic tensor; the reported time is not a model cold-start benchmark.
- `gateway-fixture.json`: actual HTTP routing and cache miss/hit using echo backends and lexical fixture embeddings.
- `routing-policy-fixture.json`: heuristic routing agreement on eight supplied labels, including two counterexamples.
- `cache-reuse-fixture.json`: synthetic labeled-vector replay showing that high similarity can still return an incorrect answer.
- `speculative-categorical-fixture.json`: seeded CPU sampling from invented distributions; no language model or decode speed measured.
- `disaggregated-cpu-fixture.json`: real separate loopback worker pools transferring signed toy state; timings are CPU/HTTP fixture paths.
- `fp8-scalar-fixture.json`: E4M3FN rounding/clipping on invented scalars, not real model activations.
- `fp8-preparation-fixture.json`: corpus-validated unexecuted ModelOpt preparation; no weights loaded.
- `perplexity-fixture.json`: arithmetic comparison of invented aligned log probabilities with real corpus-manifest checks.
- `observability-fixture.json`: checks on synthetic Prometheus samples; no GPU telemetry was collected.
- `cluster-plan-fixture.json`: generated four-node command/environment plan using illustrative addresses and placeholders; no remote command or GPU collector executed.

Run commands are documented in the corresponding project pages. Synthetic fixtures support correctness checks only. Hardware comparisons must replace them with provenance-backed traces before making performance claims.
